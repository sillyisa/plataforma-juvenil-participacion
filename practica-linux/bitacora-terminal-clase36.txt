1. ¿Qué es un sistema operativo?
Respuesta: Es el software principal de un dispositivo, que coordina todos los servicios que utiliza un usuario.

2. ¿Qué es el código abierto?
Respuesta: Es un software que esta abierto a toda persona, para que modifique, observe, añada nuevas cosas. Por ejemplo como Linux.

3. ¿Qué significa soberanía tecnológica?
Respuesta: Significa que la misma comunidad, Estado, nación. Cuente con las herramientas para gestionar su propia información, sus datos.

4. ¿Qué es Linux?
Respuesta: Es un sistema operativo de código abierto.

5. ¿Qué es Debian?
Respuesta: Igualmente es un sistema operativo de software abierto.

6. ¿Qué es un servidor?
Respuesta: Es un sistema que procesa las solicitudes y entrega un servicio, dato o aplicación por medio de una red o internet.

7. ¿Qué es una terminal?
Respuesta: Es una interfaz basada en texto que recibe comandos para interactuar directamente con el sistema operativo.
