# Clase 35 - Automatización de Notificaciones con n8n y Telegram

Durante esta clase se implementó un flujo de automatización utilizando n8n y Telegram. El objetivo fue conectar una interfaz web con un Webhook de n8n para generar el envío automático de mensajes.

### Funcionamiento del flujo

1. La página alerta-n8n.html envía una alerta simulada.
2. El nodo Webhook de n8n recibe la solicitud.
3. El flujo procesa la información recibida.
4. Un nodo de Telegram envía una notificación al chat configurado.

La implementación se realizó únicamente con fines pedagógicos y de demostración tecnológica.

**Consideraciones de seguridad**

* No se utilizaron datos reales.
* No se gestionaron casos reales.
* No se expusieron credenciales ni información confidencial.
